# Neosantara API docs extension for Gemini CLI

This extension provides documentation support for building with the Neosantara API on the Gemini CLI or other MCP-enabled tools.

## Gemini CLI Installation

```bash
gemini extensions install https://github.com/neosantara-xyz/docs-mcp.git
```

**With Auto Update**

```bash
gemini extensions install https://github.com/neosantara-xyz/docs-mcp.git --auto-update
```

Gemini CLI will automatically load the extension on startup.
